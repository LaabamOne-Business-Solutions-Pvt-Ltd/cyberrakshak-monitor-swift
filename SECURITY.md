# Security

## Reporting a vulnerability

Please tell us privately, not in a public issue:

- on GitHub: this repository's **Security** tab, then **Report a vulnerability** (only we see it), or
- by email: support@cyberrakshak.ai

What happens next, as our [disclosure policy](https://www.cyberrakshak.ai/security/disclosure) says:

- we acknowledge your report within 3 working days (a person, not an autoresponder);
- within 10 working days we tell you whether we have reproduced it, whether we agree on the impact, and roughly when
  we expect to fix it;
- we tell you when it is fixed, and credit you by name if you would like that.

If you report in good faith, we will not take legal action against you. There is no bounty.

## Advisories

A vulnerability we fix is published as a GitHub security advisory on this repository, naming the affected and the
fixed versions of the Swift package, and the release that fixes it says so in CHANGELOG.md. GitHub's Advisory Database,
which dependency auditing tools read, picks up reviewed advisories from there.

## Supported versions

Security fixes go into the latest release of the Swift package (1.x).
